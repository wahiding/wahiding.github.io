# Image slots expected by the site

Drop files here with these exact names. The layout is already built to fit them —
nothing else needs to change once they're in place.

| Filename | Used for | Suggested size/ratio |
|---|---|---|
| `hero.jpg` | Homepage hero background/portrait | Landscape, ~1600×1200, you front-and-center |
| `portrait.jpg` | About section photo | Portrait or square, ~800×1000 |
| `work-qa.jpg` | Selected Work — QA/systems (screenshot, dashboard, whiteboard, whatever reads as "QA") | 4:3 or 1:1 |
| `work-art.jpg` | Selected Work — a painting | 4:3 or 1:1 |
| `work-film.jpg` | Selected Work — a film still | 4:3 or 1:1, ideally 16:9 crop-safe |

Optional, add later:
- `favicon.png` — 512×512, used for browser tab icon
- `og-image.jpg` — 1200×630, used for social share previews
